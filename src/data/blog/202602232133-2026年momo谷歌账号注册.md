# 介绍：
现在注册google的门槛更高了，需要一个在美国的手机收取验证码才能通过。
所以我购买了成品号，绑定辅助邮箱、更改密码、添加自己国内没有注册过google的手机号，这些更改后，这个成品号就是属于我们自己的google账号了。

# 第一步：购买现成账号
- 打开**银河录像局网站**：https://nf.video/
- 在首页寻找**增值**点击（Google账号 独立账号），并购买，费泉20。
- 支付宝支付后，点击查看**车票信息**，里面有账号、密码、辅助邮箱、和简陋的使用说明。

# 第二步：
- 为了防止和google原系统的大号，发生冲突，怕被关联到。我们需要重新下载一个全新的浏览器。
- 我下载了Firefox浏览器，搜索google.com
- 然后去**车票信息**里复制，账号登陆google账号，再复制密码出入。
- 然后弹出窗口验证，这和我从教程里看到的完全不一样，这是一个非常重要的点，一不小心点错，你的号就会出问题！
![[b71cc95cdffb650aeae79225a71a85c4.jpg]]
- 这时候就要去问客服怎么解决了，但是那个客服隔了很久才回复。我差点以为我被黑吃黑了。像这种情况，也没有办法去举报他。
- 我是在11：50问的客服，客服是13:30回的我，给了我解决办法，确实很管用，一下子就成功了。
- https://2fa.run/2fa/ 后面填谷歌身份验证器验证代码，然后浏览器打开就可以获取验证码


![[6afe9b8029ccf72ec1310f6b746a7646.jpg]]

# 第三步：
- 注册好了之后需要添加：
- 辅助电话（可以用国内没有注册过google的手机号）
- 然后回到上一页，在安全与登陆的界面。
- 然后改密码，它会给你的手机号发验证码，确保你的手机可以翻墙。
- 然后绑定一个邮箱，如果你的google账号丢了，你还可以用这个邮箱找回你的Google账号。
